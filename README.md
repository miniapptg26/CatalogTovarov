# VapeCatalog

Статический Telegram Mini App — каталог вейп-шопов на чистом HTML/CSS/JS (без сборщиков и зависимостей). Отредактировали `products.json` — сайт обновился, всё остальное на месте.

## Что это

- **index.html** — страница приложения: шапка, поиск, фильтры, карточки, корзина.
- **style.css** — тёмная «вейп-эстетика» с неоновыми акцентами, адаптивная сетка, поддержка темы Telegram.
- **app.js** — логика: загрузка товаров, поиск и фильтры, корзина, копирование и отправка заказа в чат продавца.
- **products.json** — каталог товаров. Это единственный файл, который нужно редактировать для наполнения.
- **.nojekyll** — нужен GitHub Pages, чтобы статика публиковалась как есть.
- **.github/workflows/pages.yml** — автоматический деплой на GitHub Pages при пуше в `main`.

## Как заполнять каталог (products.json)

Откройте `products.json` в репозитории на GitHub и нажмите **Edit** (иконка карандаша). После правок нажмите **Commit changes** — сайт пересоберётся автоматом через минуту-две.

Поля каждого товара:

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| `id` | число | да | Уникальный числовой идентификатор |
| `name` | строка | да | Название товара |
| `brand` | строка | да | Бренд |
| `category` | строка | да | «Жидкости», «Одноразки», «POD-системы», «Аксессуары» или своя |
| `price` | число | да | Цена в рублях |
| `oldPrice` | число | нет | Старая цена (для перечёркнутой цены), можно поставить `0` |
| `description` | строка | нет | Короткое описание (показывается подсказкой на карточке) |
| `image` | строка | нет | Прямая ссылка **https://…** на картинку. Пустая строка `""` — будет эмодзи-заглушка |
| `badge` | строка | нет | `""`, `"хит"` или `"-20%"` — бейдж на карточке |
| `emoji` | строка | нет | Эмодзи для заглушки, если нет картинки |
| `available` | boolean | да | `true` / `false` — «Нет в наличии» блокирует добавление |

Пример одной позиции:

```json
{
  "id": 10,
  "name": "Жидкость «Дыня-леденец» 30 мл",
  "brand": "MistyLab",
  "category": "Жидкости",
  "price": 620,
  "oldPrice": 0,
  "description": "Сладкая дыня с леденцовой кислинкой.",
  "image": "",
  "badge": "",
  "emoji": "🍈",
  "available": true
}
```

Внимание с запятыми: между элементами массива запятая обязательна, а после последнего `}` запятой быть не должно. Валидность JSON можно проверить на https://jsonlint.com или локально: `python3 -m json.tool products.json`.

### Как добавить картинку

Поле `image` принимает только прямую ссылку на изображение (https://…). Проще всего:

1. Откройте в репозитории вкладку **Issues → New issue**.
2. Перетащите фото товара в окно ввода — GitHub загрузит файл и вставит в текст ссылку вида `https://github.com/user/assets/...`.
3. Скопируйте эту прямую ссылку в поле `image`.

Если поле `image` пустое (`""`), карточка показывает эмодзи из поля `emoji`, а если и оно пустое — эмодзи по категории.

### Как сменить контакт продавца

В файле `app.js` в самом верху:

```js
const CONFIG = {
  contactUsername: 'vape_shop' // замените на свой Telegram-username
};
```

Кнопка «Отправить заказ» копирует заказ в буфер обмена и открывает чат с этим пользователем: `https://t.me/vape_shop`.

## Как задеплоить на GitHub Pages

Установите и войдите в GitHub CLI:

```bash
gh auth login
```

Из папки проекта выполните:

```bash
git init
git add .
git commit -m "VapeCatalog"
gh repo create vape-catalog --public --source=. --push
```

Затем в GitHub: репозиторий → **Settings → Pages**:

- **Source: GitHub Actions** (рекомендуется — workflow `pages.yml` уже лежит в репозитории), или
- **Deploy from a branch** → branch `main` → folder `/ (root)`.

После первого пуша сайт будет доступен по адресу:

```
https://<ваш-логин>.github.io/vape-catalog/
```

(замените `<ваш-логин>` на имя вашего аккаунта GitHub)

## Как подключить к Telegram

1. В Telegram найдите **@BotFather** и создайте бота: `/newbot`.
2. Далее: `/menu` → **Bot Settings** → **Menu Button**.
3. Укажите URL: `https://<ваш-логин>.github.io/vape-catalog/` (с вашим логином GitHub).
4. Откройте бота — приложение запустится внутри Telegram как Mini App.

Приложение также работает в обычном браузере по той же ссылке — так удобно тестировать до подключения Menu Button.

## Локальная проверка

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000/

## Админ-режим: добавление товаров прямо из приложения

В приложение встроена админ-панель: с её помощью можно добавлять товары в каталог **прямо из Mini App**, не редактируя `products.json` вручную. Запись коммитится в репозиторий GitHub через GitHub REST API (`PUT /repos/{owner}/{repo}/contents/products.json`) — никаких внешних серверов.

### Кто может добавлять

Только пользователь Telegram с username **@g179p** (или числовым id `g179p`). Проверка выполняется по `window.Telegram.WebApp.initDataUnsafe.user` из Telegram WebApp. Для всех остальных кнопка «➕» скрыта (`display: none`), а модальное окно недоступно.

### Как получить fine-grained токен GitHub

1. GitHub → **Settings** → **Developer settings** → **Fine-grained tokens** → **New token**.
2. **Repository access**: **Only select repositories** → выберите свой репозиторий (тот, где лежит приложение).
3. **Permissions** → **Contents**: **Read and write**.
4. Нажмите **Generate token** и скопируйте значение (оно показывается только один раз).

### Как добавить товар

1. Откройте Mini App с аккаунта **@g179p** — в шапке появится круглая кнопка «➕».
2. Нажмите «➕» — откроется админ-панель.
3. Вставьте **токен**, укажите **owner** (ваш логин GitHub) и **repo** (по умолчанию `vape-catalog`). Нажмите «Проверить связь» — должно появиться «Связь OK: N товаров».
4. Заполните поля нового товара и нажмите «💾 Сохранить в каталог».
5. Через 1–2 секунды страница перезагрузится — новый товар уже в каталоге (GitHub Pages пересоберётся по workflow `pages.yml`).

`repoOwner` и `repoName` вводятся в админ-панели **один раз**: токен, owner и repo сохраняются в `localStorage` браузера (ключи `gh_token`, `gh_owner`, `gh_repo`) и автоматически подставляются при следующем открытии панели.

### Удаление записей

Удаление: в админ-панели нажмите "Загрузить список", у нужной записи нажмите 🗑 и подтвердите. Запись удаляется из репозитория тем же механизмом (commit `Remove item via Mini App`). Права токена те же (Contents: Read and write). После удаления список в админке обновляется автоматически, а GitHub Pages пересоберётся по workflow.

### Безопасность токена

- Токен хранится **только в `localStorage` браузера** и не попадает в код, репозиторий или файлы проекта.
- ⚠️ Токен **виден в DevTools** (Application → Local Storage) любому, кто откроет приложение с этого устройства.
- Используйте токен **с правами только на один репозиторий** (Only select repositories → ваш репо) и правами **Contents: Read and write**.
- При подозрении на утечку — **перевыпустите токен** в настройках GitHub (сгенерируйте новый, старый перестанет работать).
