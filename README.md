# VapeCatalog

Статический Telegram Mini App — каталог вейп-шопов на чистом HTML/CSS/JS (без сборщиков и зависимостей), в ретро-дизайне на основе коричневой палитры. Отредактировали `products.json` — сайт обновился, всё остальное на месте.

## Что это

- **index.html** — страница приложения: шапка, поиск с «✕», сортировка, чипы категорий и брендов, карточки, корзина.
- **style.css** — ретро-дизайн на основе коричневого: тёмно-коричневая тема (по умолчанию и для Telegram-тёмной) + кремовая тема (.light), serif-заголовки Georgia, пергаментный фон, адаптивная сетка.
- **app.js** — логика: загрузка товаров, поиск и фильтры, избранное, «Мне повезёт», детали товара, корзина, отправка заказа в чат продавца.
- **products.json** — каталог товаров. Это единственный файл, который нужно редактировать для наполнения.
- **.nojekyll** — нужен GitHub Pages, чтобы статика публиковалась как есть.
- **.github/workflows/pages.yml** — автоматический деплой на GitHub Pages при пуше в `main`.

## Пользовательские функции

Личные настройки (избранное, тема) хранятся локально в браузере в `localStorage` и никуда не отправляются; всё остальное состояние — фильтры (поиск, категория, бренд, диапазон цены, «В наличии», избранное), сортировка, лимит «Показать ещё» и сравнение — живёт только в рамках текущей сессии и сбрасывается при перезагрузке.

| Функция | Описание |
| --- | --- |
| ❤️ **Избранное** | Сердечко на карточке (`🤍`/`❤`) и чип «❤ Избранное» — фильтр + счётчик (число избранных). Хранится в `localStorage` (`vape_favs`) |
| 🔢 **Счётчики на чипах** | У каждого чипа категории — бейдж: сколько товаров в этой категории во **всём каталоге**; у «❤ Избранное» — число избранных |
| 🔎 **Панель активных фильтров + «Показано N из M»** | Под блоком фильтров появляется строка тегов активных фильтров: «Поиск: … ✕», «Категория: … ✕», «Бренд: … ✕», «Цена: … ✕», «В наличии ✕», «Избранное ✕», «Сравнение ✕», «Сортировка: … ✕». Крестик снимает **только этот** фильтр, в конце — кнопка «Сбросить всё». Рядом со счётчиком показывается «Показано N из M» (N — после фильтров, M — всего); без фильтров — «M записей». Панель обновляется при любом изменении состояния |
| 💰 **Фильтр по цене (второй ряд чипов)** | Чипы «до 500 ₽», «500–1500 ₽», «от 1500 ₽» — взаимоисключающие, повторный клик снимает. Фильтруют по полю `price` через `Number()`; старая цена `oldPrice` используется только для отображения |
| ↺ **Сброс фильтров** | Кнопка «↺ Сбросить» рядом с сортировкой (видна, когда активен хотя бы один фильтр) возвращает всё к дефолту. Такая же кнопка есть в пустом стейте |
| ✕ **Очистка поиска** | Кнопка «✕» внутри поля поиска (видна при непустом запросе): очищает, сбрасывает результаты, возвращает фокус. Поиск с дебаунсом 250 мс |
| 🏷️ **Бренды (второй ряд чипов)** | Уникальные бренды из данных (до 8 + «Все бренды»), фильтруются одновременно с категорией (AND); рядом — диапазоны цены |
| ⤵️ **«Показать ещё»** | Показываются первые 24 записи; если отфильтрованных больше, внизу сетки — широкая кнопка «Показать ещё (осталось K)». Клик добавляет ещё 24. Лимит сбрасывается в 24 при смене фильтров/поиска/сортировки |
| 🔄 **Обновление каталога** | Круглая кнопка «🔄» в шапке: показывает прелоадер, заново запрашивает `products.json`, перерисовывает каталог и показывает тост «Каталог обновлён: N записей». На время загрузки кнопка блокируется, иконка вращается. При ошибке показывается тост, старые данные не теряются |
| 📳 **Вибро-отклик** | Лёгкий отклик (Telegram Haptics) при избранном, выборе чипа, переключении темы; «успех» — при добавлении в корзину и отправке заказа; предупреждение — при попытке добавить 5-й товар в сравнение. Вне Telegram вызовы безопасны и ничего не ломают |
| 🧷 **Сохранение позиции скролла** | Перед открытием модалки (детали, статистика, сравнение) запоминается `window.scrollY` и возвращается при закрытии — место в списке не теряется |
| ⌨️ **Горячие клавиши** | «/» или Ctrl+K — фокус в поиске; Esc — закрыть верхнюю модалку, иначе очистить поиск; «t» — переключить тему. В модалках есть подсказка «Esc — закрыть» |
| 🔗 **Поделиться каталогом** | Кнопка «🔗» в шапке копирует ссылку на страницу и показывает тост «Ссылка скопирована». В статистике есть строка «✉️ Написать продавцу» — открывает чат с `CONFIG.contactUsername` через `Telegram.WebApp.openTelegramLink`, иначе через `window.open` |
| 🦴 **Скелетон первой загрузки** | Во время первой загрузки вместо пустого экрана показываются 4 карточки-заглушки с мягким мерцанием (рядом с прелоадером) |
| 🧭 **Плавная прокрутка к каталогу** | После выбора чипа категории, если пользователь выше сетки, страница плавно прокручивается к каталогу с учётом липкой шапки |

| 📊 **Статистика** | Кнопка 📊 в шапке: всего товаров, в наличии, категорий, средняя цена, акции, самый дорогой/дешёвый |
| 📤 **Экспорт выборки** | Кнопка 📤 копирует в буфер прайс текущей выборки («Прайс VapeCatalog <дата>», «1) <имя> (<бренд>) — <цена> ₽») |
| ⚖️ **Сравнение товаров** | Кнопка ⚖️ на карточке (до 4), панель «⚖️ Сравнить (N)», модалка-таблица: цена (лучшая — зелёная), скидка %, наличие, категория. Сессия, без сохранения |
| 🔦 **Подсветка поиска** | Совпадения запроса подсвечиваются жёлтым `mark` (безопасно, без `innerHTML`) |
| 🌗 **Тема** | Кнопка «🌙/☀️», выбор в `localStorage` (`vape_theme`), без мигания при загрузке |
| 🎲 **Мне повезёт** | Кнопка в шапке открывает случайную карточку из текущей выборки |
| 📖 **Детали** | Клик по карточке открывает модалку: квадратное медиа (фото 120px или эмодзи), цена, кликабельная категория, наличие, описание, кнопки «В корзину», «Сравнить», «Поделиться» |
| 🛒 **Корзина и заказ** | Кнопка «+ В корзину» на карточке и в деталях, панель «Ваш заказ» с итогом и «Очистить». Кнопка «Отправить заказ» открывает личный чат с продавцом (`CONFIG.contactUsername`) и подставляет текст заказа в поле сообщения — останется нажать «Отправить»; заказ в буфер не копируется, корзина не очищается |
| ⏳ **Прелоадер + анимации** | Спиннер при загрузке, стаггер-появление карточек, кнопка «↑» при прокрутке более 600px |

## Наполнение каталога

Каталог наполняется через файл `products.json` на GitHub: откройте файл → **Edit** → добавьте/измените/удалите блок записи по шаблону из раздела ниже → **Commit changes**. В `localStorage` хранятся только избранное и тема.

Поля каждого товара:

| Поле | Тип | Обязательно | Описание |
| --- | --- | --- | --- |
| `id` | число | да | Уникальный числовой идентификатор |
| `name` | строка | да | Название товара |
| `brand` | строка | да | Бренд (показывается на карточке и фильтруется чипом) |
| `category` | строка | да | «Жидкости», «Одноразки», «POD-системы», «Аксессуары» или своя |
| `price` | число | да | Цена в рублях |
| `oldPrice` | число | нет | Старая цена (для перечёркнутой), можно `0` |
| `description` | строка | нет | Короткое описание (полностью — в модалке деталей) |
| `image` | строка | нет | Прямая ссылка **https://…** на картинку. Пустая `""` — эмодзи-заглушка |
| `badge` | строка | нет | `""`, `"хит"` или `"-20%"` — бейдж на карточке |
| `emoji` | строка | нет | Эмодзи для заглушки, если нет картинки |
| `available` | boolean | да | `true` / `false` — «Нет в наличии» блокирует добавление в корзину |

### Пример JSON-блока для вставки

```json
{
  "id": 10,
  "name": "Жидкость «Дыня-леденец» 30 мл",
  "brand": "MistyLab",
  "category": "Жидкости",
  "price": 620,
  "oldPrice": 0,
  "description": "Сладкая дыня с леденцовой кислинкой.",
  "image": "",
  "badge": "",
  "emoji": "🍈",
  "available": true
}
```

Внимание с запятыми: между элементами массива запятая обязательна, после последнего `}` запятой быть не должно. Валидность JSON можно проверить локально:

```bash
python3 -m json.tool products.json
```

## Изображения

Поле `image` = **прямая `https://`-ссылка** на картинку (например `https://picsum.photos/seed/.../160/160` или фото на любом хостинге — Imgur и т.п.).

- Картинка подстраивается под квадрат (`object-fit: cover`): 80×80 в карточке, 120×120 в модалке деталей. У `<img>` заданы `loading="lazy"`, `decoding="async"`, `referrerpolicy="no-referrer"`, `width`/`height` и `alt` = название товара.
- До загрузки картинка прозрачная, после загрузки — плавное появление 0.2s; из-за `aspect-ratio 1/1` и фон-заглушки вёрстка не «прыгает».
- Ссылка `http://` (не https) — не грузится, сразу эмодзи-заглушка; ошибка загрузки — тоже эмодзи (повторных попыток нет).
- `"image": ""` (пусто) → эмодзи из поля `emoji`, а если его нет — по категории (`🧪` Жидкости, `💨` Одноразки и т.д.).
- Демо: фото у товаров id 1, 3, 5 (`https://picsum.photos/seed/vapeN/160/160`), у остальных — эмодзи.

## Как сменить контакт продавца

В файле `app.js` в самом верху:

```js
const CONFIG = {
  contactUsername: 'g179p' // замените на свой Telegram-username
};
```

Кнопка «Отправить заказ» открывает личный чат с @g179p в Telegram и подставляет текст заказа в поле сообщения — останется нажать «Отправить». Контакт задаётся в `app.js`: `CONFIG.contactUsername`. Ссылка формируется как `https://t.me/<username>?text=<текст заказа>`, текст кодируется через `encodeURIComponent`. Заказ **не копируется в буфер обмена**, панель «Ваш заказ» остаётся открытой — содержимое можно поправить и отправить повторно.

Telegram ограничивает длину предзаполненного текста в ссылке, поэтому при очень длинном заказе часть позиций может не поместиться: список обрезается по целым позициям (лимит ссылки — 3800 символов), а вместо отброшенных строк добавляется «…и ещё N позиций». Строка «Итого» при этом остаётся в тексте.

Функции заказа в `app.js` чистые и легко проверяются отдельно: `buildOrderText(cartItems, total)` — текст заказа, `buildOrderLink(username, text)` — ссылка на чат, `fitOrderText(items, total)` — обрезка под лимит.

## Как задеплоить на GitHub Pages

Установите и войдите в GitHub CLI:

```bash
gh auth login
```

Из папки проекта выполните:

```bash
git init
git add .
git commit -m "VapeCatalog"
gh repo create vape-catalog --public --source=. --push
```

Затем в GitHub: репозиторий → **Settings → Pages**:

- **Source: GitHub Actions** (рекомендуется — workflow `pages.yml` уже лежит в репозитории), или
- **Deploy from a branch** → branch `main` → folder `/ (root)`.

После первого пуша сайт будет доступен по адресу:

```
https://<ваш-логин>.github.io/vape-catalog/
```

## Как подключить к Telegram

1. В Telegram найдите **@BotFather** и создайте бота: `/newbot`.
2. Далее: `/menu` → **Bot Settings** → **Menu Button**.
3. Укажите URL: `https://<ваш-логин>.github.io/vape-catalog/` (с вашим логином GitHub).
4. Откройте бота — приложение запустится внутри Telegram как Mini App.

Приложение также работает в обычном браузере по той же ссылке — так удобно тестировать до подключения Menu Button.
